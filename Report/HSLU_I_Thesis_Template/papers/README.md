# Papers

Store PDF copies of papers cited in this thesis here.
Suggested naming: `AuthorYear_ShortTitle.pdf`

---

## BibTeX entry templates — copy into references.bib

### Conference / workshop paper
```bibtex
@inproceedings{author_keyword_year,
    title = {Paper Title},
    author = {Surname, Firstname and Surname, Firstname},
    booktitle = {Proceedings of the Conference Name ({ABBREV})},
    pages = {1--10},
    year = {2024},
    doi = {10.xxxx/xxxxxx},
}
```

### Journal article
```bibtex
@article{author_keyword_year,
    title = {Article Title},
    author = {Surname, Firstname and Surname, Firstname},
    journal = {Journal Name},
    volume = {1},
    number = {1},
    pages = {1--20},
    year = {2024},
    doi = {10.xxxx/xxxxxx},
}
```

### Book
```bibtex
@book{author_keyword_year,
    title = {Book Title},
    author = {Surname, Firstname and Surname, Firstname},
    year = {2024},
    publisher = {Publisher Name},
    isbn = {978-x-xxx-xxxxx-x},
}
```

### arXiv / preprint
```bibtex
@misc{author_keyword_year,
    title = {Paper Title},
    author = {Surname, Firstname and Surname, Firstname},
    year = {2024},
    url = {https://arxiv.org/abs/xxxx.xxxxx},
    eprint = {xxxx.xxxxx},
    eprinttype = {arXiv},
}
```
